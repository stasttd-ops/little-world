# little world ♡

Затишний cute-сайт для подруги: п'ять котиків зі своїм характером, інтерактивна
кімната, три міні-ігри та музичний плеєр із треками Jann. Frontend — чистий
HTML/CSS/JS без збірки. Backend — маленький C++17 HTTP-сервер без зовнішніх
залежностей (тільки POSIX-сокети зі стандартної бібліотеки), тож для запуску
достатньо звичайного компілятора — не потрібно нічого качати чи ставити.

## Структура проєкту

```
project/
├── CMakeLists.txt        збірка через CMake (опційно)
├── main.cpp               точка входу бекенду + маленькі JSON-роути
├── include/
│   └── httpserver.hpp      сам HTTP-сервер (сокети, статичні файли, роутинг)
├── data/
│   ├── cats.json           характери й репліки п'яти котиків
│   ├── music.json          плейлист Jann (назви, тривалість, посилання на Spotify)
│   └── stats.json          зберігається автоматично: лічильники поглажень і рекорди ігор
└── public/                 усе, що бачить браузер
    ├── index.html
    ├── css/style.css
    ├── js/app.js
    └── images/favicon.svg
```

## Запуск

Знадобиться лише компілятор C++17 (g++ або clang++) — жодних додаткових
бібліотек ставити не треба.

### Варіант 1 — напряму через g++ (найпростіше)

```bash
cd project
g++ -std=c++17 -O2 -pthread -Iinclude main.cpp -o server
./server
```

Сайт відкриється на **http://localhost:8080**

Щоб запустити на іншому порті:

```bash
./server 3000
```

### Варіант 2 — через CMake

```bash
cd project
cmake -B build
cmake --build build
./build/server
```

(CMake запускає той самий бінарник — просто зручніше для IDE.)

## Що вміє бекенд

Сервер віддає весь вміст `public/` як звичайний веб-сайт і додатково має
кілька легких JSON-роутів:

| Метод | Шлях               | Що робить                                   |
|-------|--------------------|----------------------------------------------|
| GET   | `/api/cats`         | список котиків (ім'я, характер, репліки)     |
| GET   | `/api/music`        | плейлист Jann                                |
| GET   | `/api/stats`        | поточна статистика (погладження, рекорди)    |
| POST  | `/api/stats/pet`    | `{ "catId": "mochi" }` — рахує погладження    |
| POST  | `/api/stats/game`   | `{ "game": "catch", "score": 12 }` — рекорди |

Статистика зберігається у `data/stats.json` і переживає перезапуск сервера.
Якщо API з якоїсь причини недоступне (наприклад, файл відкрили напряму
подвійним кліком без сервера), frontend автоматично переходить на вбудовані
резервні дані з `app.js` — сайт все одно працює, просто без збереження
рекордів між сесіями.

## Про музику

Реальні MP3 файли Jann у проєкт **не включені** — завантажувати треки з
неліцензійних джерел незаконно, а офіційного безкоштовного API для повного
відтворення пісень Jann не існує. Тому плеєр:

- показує реальні назви треків і їх тривалість (`data/music.json`);
- відтворює короткий згенерований у браузері (Web Audio) мелодійний
  прев'ю-тон для кожного треку — це повністю легально, бо звук генерується
  на льоту, а не копіюється з чужого запису;
- має кнопку **Spotify ↗**, яка веде на офіційну сторінку пошуку треку —
  так подруга зможе прослухати саму пісню легально.

Якщо у вас є власні ліцензійні mp3-файли Jann (куплені або з дозволом), їх
можна покласти в `public/music/<id>.mp3` (id треку — з `data/music.json`,
наприклад `gladiator.mp3`) і підключити напряму в `app.js` замість
синтезованого тону — місце під це вже підготовлене (папка `public/music/`
створена саме для цього).

## Адаптивність

Перевірено на роздільностях 1920×1080, 1366×768, 390×844 та 375×812 —
навігація перетворюється на гамбургер-меню, кімната та плеєр підлаштовуються
під ширину екрана, усі кнопки достатньо великі для дотику.

## Нотатка про помилки

- Якщо `data/cats.json` чи `data/music.json` відсутні — сервер віддасть
  порожній, але коректний JSON, а frontend підставить резервні дані.
- Якщо картинка чи будь-який файл не знайдено — сервер повертає 404, а не
  падає.
- Порт зайнятий? Запустіть з іншим номером: `./server 3000`.
